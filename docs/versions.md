# Versions des composants (étape 3.1 du plan)

Relevé fait le **3 novembre 2026**. Règle du plan : la version d'un composant ne change pas sans ticket.
Les colonnes « Source » renvoient aux pages ou registres réellement consultés. Une case **à confirmer**
signifie que la source n'a pas pu être lue : ce n'est pas une information vérifiée.

## Limites du relevé

- Les sites `bahmni.atlassian.net`, `www.bahmni.org` et `www.odoo.com` n'étaient pas joignables depuis l'environnement
  de travail ; les licences et notes de version qui en dépendent sont **à confirmer**.
- Les licences marquées « connaissance générale » proviennent de la mémoire de l'auteur, pas d'une page lue.
- Exécutions du 3 nov. 2026 : le démon Docker a pu être lancé (`dockerd`). Docker Hub est limité (429) et quay.io refusé ;
  les images ont été tirées par `mirror.gcr.io` (PostgreSQL 16.15, Nginx 1.30.6, Prometheus 3.15.1, Grafana 13.3.0,
  node-exporter 1.12.1). L'image Keycloak n'a **pas** pu être tirée : Keycloak a été exécuté depuis son archive GitHub,
  sous Java 21. Voir `docs/verification.md`.
- Node 26.13.0 : suite complète exécutée (132 tests) en plus de Node 22.23.4.
