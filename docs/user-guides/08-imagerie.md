# Fiche 8 · Imagerie

## Français

**Écran : « Imagerie »**

1. La carte d'un examen n'apparaît **qu'après le paiement**. Elle porte déjà son **numéro d'accession** (« ACC-… »).
2. **Programmer** : date et heure → « Programmer » (ou « Commencer l'examen » directement).
3. Sur l'appareil, choisissez le patient dans la **liste de travail** (elle vient du système : pas de ressaisie, donc pas d'erreur
   d'identité). **Ne retapez jamais le nom à la main.**
4. **« Commencer l'examen »**. Les images de l'appareil arrivent seules : « Images DICOM de l'appareil » → **« Voir les images »**.
   Si l'écran affiche **« Identifiant patient différent : non affiché »**, **ne rien conclure** : l'image porte un autre patient ;
   prévenir le responsable et refaire l'envoi depuis la liste de travail.
5. Vous pouvez aussi **ajouter une image** (PNG, JPEG ou PDF).
6. **Description** et **Conclusion** → **« Enregistrer le compte rendu »**. Le médecin le voit alors dans le dossier du patient.
   Une correction crée une **nouvelle version** (l'ancienne reste consultable).

**À retenir** : les aperçus de l'écran ne remplacent pas un poste de diagnostic pour les radiologues.

## العربية

**الشاشة: «التصوير الطبي»**

١. لا تظهر بطاقة الفحص **إلا بعد الدفع**، وتحمل مسبقًا **رقم الدخول** («ACC-…»).
٢. **جدولة**: التاريخ والوقت ← «جدولة» (أو «بدء الفحص» مباشرة).
٣. على الجهاز اختر المريض من **قائمة العمل** (تأتي من النظام: لا إعادة إدخال، فلا خطأ في الهوية). **لا تكتب الاسم يدويًا أبدًا.**
٤. **«بدء الفحص»**. تصل صور الجهاز وحدها: «صور DICOM من الجهاز» ← **«عرض الصور»**. إذا ظهر **«معرّف مريض مختلف: غير معروضة»**
فلا تستنتج شيئًا: الصورة تخص مريضًا آخر؛ أبلغ المسؤول وأعد الإرسال من قائمة العمل.
٥. يمكنك أيضًا **إضافة صورة** (PNG أو JPEG أو PDF).
٦. **الوصف** و**الخلاصة** ← **«حفظ التقرير»**. يراه الطبيب بعدها في ملف المريض. التصحيح ينشئ **نسخة جديدة** (تبقى القديمة متاحة).

**للتذكير**: المعاينات على الشاشة لا تغني أخصائيي الأشعة عن محطة التشخيص.
