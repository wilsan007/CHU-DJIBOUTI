# Fiche 7 · Stocks et matériel

## Français

**Écran : « Stocks »** (magasinier) · **« Matériel utilisé »** (tout agent)

**Magasinier**

1. **« Réception »** : cherchez l'article (code ou nom), saisissez **numéro de lot**, **péremption**, **quantité** →
   **« Enregistrer la réception »**. Les médicaments relèvent de la pharmacie (refusé ici).
2. **« Transferts »** : dépôt d'origine → dépôt de destination (ex. Magasin central → Réserve du laboratoire), lot, quantité.
3. **« Niveaux et alertes »** : sous le seuil, péremption proche, périmé. **« Fixer le seuil »** pour chaque article.
4. **« Recettes d'actes »** : ce que chaque acte consomme (ex. la glycémie : 1 seringue + 1 réactif). Elles sont prélevées
   **automatiquement** quand le service termine l'acte. Indiquez le **responsable de la recette**.
5. **« Manques à régulariser »** : si le stock manquait à ce moment-là, l'acte n'est **pas bloqué** : un manque est noté ; vous
   le régularisez après réapprovisionnement.

**Tout agent** : « Matériel utilisé » → article, quantité, patient (facultatif), motif (pansement, perfusion…) → « Enregistrer l'utilisation ».

**À retenir** : on sort toujours le lot qui expire **en premier**. Un lot périmé ne se sort pas.

## العربية

**الشاشة: «المخزون»** (أمين المخزن) · **«المعدات المستعملة»** (كل موظف)

**أمين المخزن**
١. **«استلام»**: ابحث عن المادة (رمز أو اسم)، أدخل **رقم الدفعة** و**تاريخ الانتهاء** و**الكمية** ← **«تسجيل الاستلام»**. الأدوية من
اختصاص الصيدلية (تُرفض هنا).
٢. **«التحويلات»**: مستودع المصدر ← مستودع الوجهة (مثل المخزن المركزي ← احتياطي المختبر)، الدفعة، الكمية.
٣. **«المستويات والتنبيهات»**: دون الحد الأدنى، قرب انتهاء الصلاحية، منتهٍ. **«تحديد الحد الأدنى»** لكل مادة.
٤. **«وصفات الإجراءات»**: ما يستهلكه كل إجراء (مثل سكر الدم: حقنة + كاشف). تُسحب **تلقائيًا** عندما تنهي المصلحة الإجراء.
اذكر **مسؤول الوصفة**.
٥. **«نواقص للتسوية»**: إذا نقص المخزون وقتها **لا يُمنع** الإجراء: يُسجَّل نقص وتسوّيه بعد التزوّد.

**كل موظف**: «المعدات المستعملة» ← المادة، الكمية، المريض (اختياري)، السبب (ضمادة، مصل…) ← «تسجيل الاستعمال».

**للتذكير**: يُخرج دائمًا الدفعة **الأقرب انتهاءً**. الدفعة المنتهية الصلاحية لا تُخرج.
