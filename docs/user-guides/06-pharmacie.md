# Fiche 6 · Pharmacie

## Français

**Écran : « Pharmacie »**

1. Onglet **« Ordonnances à servir »** : ouvrez l'ordonnance (ou saisissez/scannez son **code QR** puis « Vérifier » : une
   ordonnance remplacée ouvre la version en vigueur ; « non valide ou déjà servie » = ne pas délivrer).
2. Lisez **« Allergies connues »** et **« Alertes justifiées par le prescripteur »** avant de délivrer.
3. Pour chaque ligne : **Prescrit / Servi / Reste**. Saisissez la **quantité à servir** puis **« Délivrer »**. La délivrance
   **partielle** est possible (le reste demeure à servir). Le système prélève sur les **lots qui expirent en premier**.
4. **Stock insuffisant** : la délivrance est refusée, rien n'est enregistré ; servez ce qui est disponible ou prévenez le magasin.
5. Onglet **« Stock et alertes »** : stock par lot, **péremption proche** (6 mois) / **périmé**, articles **sous le seuil minimal**.

**À retenir** : ne jamais délivrer un lot périmé ; une ordonnance déjà servie ne se ressert pas ; la pharmacie ne gère que les
**médicaments** (le matériel et les réactifs sont au magasin, fiche 7).

## العربية

**الشاشة: «الصيدلية»**

١. تبويب **«وصفات للصرف»**: افتح الوصفة (أو أدخل/امسح **رمز QR** ثم «تحقق»: الوصفة المستبدَلة تفتح النسخة السارية؛
«غير صالحة أو مصروفة سابقًا» = لا تصرف).
٢. اقرأ **«الحساسيات المعروفة»** و**«التنبيهات المبرَّرة من الواصف»** قبل الصرف.
٣. لكل سطر: **الموصوف / المصروف / المتبقي**. أدخل **الكمية المصروفة** ثم **«صرف»**. **الصرف الجزئي** ممكن (يبقى الباقي).
يسحب النظام من **الدفعات الأقرب انتهاءً** أولًا.
٤. **مخزون غير كافٍ**: يُرفض الصرف ولا يُسجَّل شيء؛ اصرف المتوفر أو أبلغ المخزن.
٥. تبويب **«المخزون والتنبيهات»**: المخزون حسب الدفعة، **قرب انتهاء الصلاحية** (6 أشهر) / **منتهي الصلاحية**، المواد **دون الحد الأدنى**.

**للتذكير**: لا تصرف دفعة منتهية الصلاحية أبدًا؛ الوصفة المصروفة لا تُصرف ثانية؛ الصيدلية تدير **الأدوية** فقط (المعدات والكواشف في
المخزن، البطاقة ٧).
