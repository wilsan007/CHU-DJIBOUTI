# Fiche 3 · Médecin

## Français

**Écran : « Médecin » → « File d'attente de consultation »**

1. **Appeler** le patient suivant (ou **Ouvrir** son dossier). Lisez en haut : **allergies**, historique, résultats validés,
   comptes rendus d'imagerie, messages du laboratoire.
2. **Commencer la consultation** : motif, examen clinique, notes. « Enregistrer le brouillon » à tout moment. Si un collègue a
   modifié le dossier en même temps, l'écran affiche les deux versions : comparez puis « Garder ma version » ou « Reprendre la version enregistrée ».
3. **Constantes** : mesure + valeur. Une valeur inhabituelle demande « je confirme la mesure » ; une valeur impossible est refusée.
4. **Diagnostics** : cherchez par code ou mot (sans accents), le premier est le diagnostic **principal**.
5. **Ordonnance** : médicament, dose, jours. Le système vérifie **allergies et interactions** ; une alerte demande une
   **justification écrite** pour continuer. « Signer » : l'ordonnance reçoit un code QR pour la pharmacie.
6. **Demander des prestations** (analyse, radio, acte) : cochez, **« Envoyer à la caisse »**. **Aucun service ne la reçoit avant
   le paiement du patient.**
7. **Clôturer** la consultation. Une consultation clôturée ne se modifie plus (une correction crée une nouvelle version).

**Urgence vitale** : cochez « Urgence vitale… » et écrivez la **justification** (obligatoire) : les services travaillent tout de
suite, la caisse régularise ensuite. Tout est tracé à votre nom.

**Valeur critique** (ex. glycémie 30 mmol/L) : un message rouge apparaît ; cliquez **« Accusé de réception »**. Sans accusé dans
le délai fixé, le système prévient le responsable désigné.

**Hospitaliser** : écran « Hospitalisation » → « Nouveau séjour » (voir fiche infirmier).

## العربية

**الشاشة: «الطبيب» ← «طابور الاستشارة»**

١. **نادِ** المريض التالي (أو **افتح** ملفه). اقرأ في الأعلى: **الحساسيات**، السوابق، النتائج المصادَق عليها، تقارير التصوير،
رسائل المختبر.
٢. **ابدأ الاستشارة**: سبب الزيارة، الفحص السريري، الملاحظات. «حفظ المسودة» في أي وقت. إذا عدّل زميل الملف في الوقت نفسه
تعرض الشاشة النسختين: قارن ثم «أبقِ نسختي» أو «خذ النسخة المحفوظة».
٣. **العلامات الحيوية**: القياس + القيمة. القيمة غير المعتادة تتطلب «أؤكد القياس»؛ والمستحيلة تُرفض.
٤. **التشخيصات**: ابحث بالرمز أو بكلمة؛ الأول هو التشخيص **الرئيسي**.
٥. **الوصفة**: الدواء والجرعة والأيام. يفحص النظام **الحساسيات والتداخلات**؛ والتنبيه يتطلب **تبريرًا مكتوبًا** للمتابعة. «توقيع»:
تحصل الوصفة على رمز QR للصيدلية.
٦. **طلب خدمات** (تحليل، أشعة، إجراء): حدّد ثم **«إرسال إلى الصندوق»**. **لا تصل أي مصلحة قبل دفع المريض.**
٧. **أغلق** الاستشارة. الاستشارة المغلقة لا تُعدَّل (التصحيح ينشئ نسخة جديدة).

**الحالة الحرجة**: حدّد «حالة حرجة…» واكتب **التبرير** (إلزامي): تعمل المصالح فورًا والصندوق يسوّي لاحقًا. كل شيء مسجَّل باسمك.

**قيمة حرجة** (مثل سكر 30 ملمول/لتر): تظهر رسالة حمراء؛ اضغط **«إشعار بالاستلام»**. بلا إشعار في المدة المحددة ينبّه النظام
المسؤول المعيَّن.

**الإيواء**: شاشة «الاستشفاء» ← «إقامة جديدة» (انظر بطاقة الممرض).
