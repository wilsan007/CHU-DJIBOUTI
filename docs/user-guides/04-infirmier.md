# Fiche 4 · Infirmier et aide-soignant

## Français

**Écran : « Hospitalisation »** (et « Matériel utilisé », voir fiche 7)

**Séjour d'un patient**

1. Le médecin ou vous créez le séjour : onglet **« Nouveau séjour »** → patient de la file d'attente → la **première nuit** est
   obligatoire (une seule) ; ajoutez éventuellement un **acte initial** (opération…) → **« Envoyer le forfait à la caisse »**.
2. Le patient **paie le forfait à la caisse** (avec ou sans remise). **Avant ce paiement, le lit ne peut pas être attribué.**
3. Onglet **« Séjours »** → le séjour → choisissez un **lit libre** → **« Admettre au lit »** (le plan est dans l'onglet « Lits »).
4. Pendant le séjour : **« Soin courant » → « Ajouter le soin »** (facturé à la sortie, avec les nuits supplémentaires ; le solde
   prévisionnel est affiché). Un **acte lourd** (grande opération…) : **« Demander un acte lourd »** : il est **payé d'abord**, à part.
5. **Sortie** : le médecin clique **« Ordonner la sortie »** ; la **facture de sortie** apparaît ; le patient la paie ; vous cliquez
   **« Enregistrer la sortie du patient »**. Tant que la facture n'est pas payée, la sortie est refusée (seule la direction peut
   autoriser une sortie impayée, avec un motif écrit).

**Matériel** : tout ce que vous utilisez (seringue, pansement, perfusion) s'enregistre dans « Matériel utilisé » (patient facultatif + motif).

## العربية

**الشاشة: «الاستشفاء»** (و«المعدات المستعملة»، انظر البطاقة ٧)

**إقامة المريض**
١. يُنشئ الطبيب أو أنت الإقامة: تبويب **«إقامة جديدة»** ← مريض من الطابور ← **الليلة الأولى** إلزامية (واحدة فقط)؛ أضف عند الحاجة
**إجراءً أوليًا** (عملية…) ← **«إرسال الحزمة إلى الصندوق»**.
٢. يدفع المريض **الحزمة في الصندوق** (بتخفيض أو بدونه). **قبل هذا الدفع لا يمكن تخصيص السرير.**
٣. تبويب **«الإقامات»** ← الإقامة ← اختر **سريرًا شاغرًا** ← **«إدخال إلى السرير»** (مخطط الأسرّة في تبويب «الأسرّة»).
٤. أثناء الإقامة: **«رعاية جارية» ← «إضافة الرعاية»** (تُفوتَر عند الخروج مع الليالي الإضافية؛ يُعرض الرصيد المتوقع). **الإجراء الثقيل**
(عملية كبرى…): **«طلب إجراء ثقيل»**: **يُدفع أولًا** وبشكل منفصل.
٥. **الخروج**: يضغط الطبيب **«أمر بالخروج»**؛ تظهر **فاتورة الخروج**؛ يدفعها المريض؛ ثم تضغط **«تسجيل خروج المريض»**. ما لم تُدفع
الفاتورة يُرفض الخروج (الإدارة وحدها تستطيع السماح بخروج غير مدفوع بسبب مكتوب).

**المعدات**: كل ما تستعمله (حقنة، ضمادة، مصل) يُسجَّل في «المعدات المستعملة» (المريض اختياري + السبب).
