# Fiche 5 · Laboratoire (technicien et biologiste)

## Français

**Écran : « Laboratoire »**

**Technicien**

1. **« Demandes à prélever »** : la demande n'existe **qu'après le paiement**. Choisissez-la.
2. **Scannez la carte du patient** (« Scan de la carte du patient ») : le prélèvement est **refusé si ce n'est pas le bon patient**.
   Indiquez le type d'échantillon → **« Prélever »** → **« Imprimer l'étiquette »** (collez-la sur le tube).
3. À la paillasse : **« Réceptionner »** (scan de l'étiquette). Tube inutilisable : **« Rejeter »** avec le **motif** : le médecin est prévenu.
4. **Résultat** : saisie manuelle ou, si l'automate est relié, arrivée automatique sur le **bon échantillon** (jamais un autre).
5. **« Validation technique »** quand tous les résultats sont saisis.

**Biologiste** (une autre personne que le technicien) 6. **« Validation biologique »** : seul un résultat **validé** devient visible du médecin et du patient. 7. **Valeurs critiques** : le médecin est alerté et doit accuser réception ; sans accusé, escalade au responsable désigné.
Réglez les **plages de référence** (par sexe et âge) : le système ne signale « normal / bas / haut / critique » qu'avec elles.

**À retenir** : _deux personnes distinctes_ valident. Une analyse « non configurée » se signale au biologiste (catalogue à compléter).

## العربية

**الشاشة: «المختبر»**

**التقني**
١. **«طلبات للسحب»**: لا يوجد الطلب **إلا بعد الدفع**. اختره.
٢. **امسح بطاقة المريض** («مسح بطاقة المريض»): يُرفض السحب **إن لم يكن المريض الصحيح**. حدّد نوع العيّنة ← **«سحب العيّنة»** ←
**«طباعة الملصق»** (الصقه على الأنبوب).
٣. عند الطاولة: **«استلام»** (مسح الملصق). أنبوب غير صالح: **«رفض»** مع **السبب**: يُنبَّه الطبيب.
٤. **النتيجة**: إدخال يدوي، أو وصول تلقائي إلى **العيّنة الصحيحة** (لا غيرها) إذا كان الجهاز موصولًا.
٥. **«المصادقة التقنية»** عند إدخال كل النتائج.

**الطبيب الحيوي** (شخص غير التقني)
٦. **«المصادقة الحيوية»**: النتيجة **المصادَق عليها** وحدها تصبح مرئية للطبيب وللمريض.
٧. **القيم الحرجة**: يُنبَّه الطبيب وعليه الإشعار بالاستلام؛ بلا إشعار يُصعَّد الأمر إلى المسؤول المعيَّن. اضبط **المجالات المرجعية**
(حسب الجنس والعمر): لا يشير النظام إلى «طبيعي / منخفض / مرتفع / حرج» إلا بها.

**للتذكير**: _شخصان مختلفان_ يصادقان. التحليل «غير المهيّأ» يُبلَّغ به الطبيب الحيوي (الدليل يحتاج إكمالًا).
